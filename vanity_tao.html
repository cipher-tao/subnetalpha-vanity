// Importing your vanity wallet into btcli

Une fois ton adresse trouvée, copie le mnemonic et importe-le avec btcli :

# Coldkey (wallet principal)
btcli wallet regen_coldkey --wallet.name <name> \\
  --mnemonic "word1 word2 word3 ... word24"

# Hotkey (mining/staking)

btcli wallet regen_hotkey –wallet.name  –wallet.hotkey  \
–mnemonic “word1 word2 word3 … word24”

⚠ Sauvegarde le mnemonic dans un gestionnaire de mots de passe OU sur papier hors-ligne. Personne ne pourra le récupérer si tu le perds.

12 ou 24 mots = même format BIP39, le 24 mots est plus sécurisé (256 bits d’entropie vs 128).

What this tool does

Generates Bittensor (TAO) wallet addresses matching a custom pattern, by brute-forcing random seed phrases until one produces an address you like. Pure crypto, no magic. ```

How your secret is protected

  • All computation runs inside your browser only. No server, no API call, no logging.
  • Your mnemonic NEVER leaves this page. There is no network code that sends it anywhere.
  • Source is open on GitHub. Inspect it. Diff it against this page (DevTools → Sources).

Recommended workflow

  • For high-value addresses: disconnect your internet before clicking Start. The trust badge above will turn green.
  • Save the mnemonic offline (paper or hardware password manager) before transferring any TAO.
  • Always verify the generated address by importing it into btcli on a test setup and confirming it matches.
